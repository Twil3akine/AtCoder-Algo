# 多角形の面積を小数の誤差なく求めたい、靴紐公式・符号付き面積の2倍

## こういうときに使う

**靴紐公式・符号付き面積の2倍**：多角形の面積を小数の誤差なく求めたい場合に適しています。

## 考え方と使い方

頂点列を順番に並べ、隣接する2点の外積を足し合わせます。 `polygon_area2(&points)` を使います。結果の絶対値を2で割ったものが、自己交差のない多角形の面積です。

## 注意・計算量

返り値は符号付きで、頂点順によって正負が変わります。自己交差する多角形では単純な面積と一致しません。

**計算量**：O(N)。

**対応API**：[`polygon_area2`](atcoder::geometry::polygon_area2)。
