# 原点を基準に点を角度順へ並べたい、偏角ソート

## こういうときに使う

**偏角ソート**：原点を基準に点を角度順へ並べたい場合に適しています。

## 考え方と使い方

浮動小数点の `atan2` を使わず、半平面と外積で角度の順序を比較できます。 `points.sort_by(|&a, &b| argcmp(a, b))` を使用します。任意の点を中心にしたい場合は、その点を引き算したベクトルを比較します。

## 注意・計算量

原点の点は除いてください。同じ方向の点は距離順に並べ替えられません。

**計算量**：比較 O(1)、全体のソート O(N log N)。

**対応API**：[`argcmp`](atcoder::geometry::argcmp)。
