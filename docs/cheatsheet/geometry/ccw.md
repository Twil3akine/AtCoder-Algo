# 3点の位置関係や、点が直線の左右どちらにあるか判定したい、外積・ccw

## こういうときに使う

**外積・ccw**：3点の位置関係や、点が直線の左右どちらにあるか判定したい場合に適しています。

## 考え方と使い方

ベクトルの外積の符号で、反時計回り・時計回り・一直線を判定できます。 `ccw(a, b, c)` の符号を調べます。正なら有向直線 `a -> b` の左側、負なら右側、0なら同一直線上です。

## 注意・計算量

直線上かどうかだけでは線分上かは判定できません。座標の積が `isize` に収まる必要があります。

**計算量**：O(1)。

**対応API**：[`ccw`](atcoder::geometry::ccw)、[`Point`](atcoder::geometry::Point)、[`on_segment`](atcoder::geometry::on_segment)。
