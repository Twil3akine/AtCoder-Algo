# 2点間の距離を平方根を取らずに比較したい、距離の2乗

## こういうときに使う

**距離の2乗**：2点間の距離を平方根を取らずに比較したい場合に適しています。

## 考え方と使い方

距離の平方根は大小関係を変えないため、2乗同士の比較で十分です。 `Point::distance_squared(other)` を使い、距離の閾値も2乗にして比較します。

## 注意・計算量

座標差や2乗が `isize` に収まることを確認してください。

**計算量**：O(1)。

**対応API**：[`Point::distance_squared`](atcoder::geometry::Point::distance_squared)。
