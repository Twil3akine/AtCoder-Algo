# 2つの線分が交差するか、端点で接触するかを判定したい、線分交差判定

## こういうときに使う

**線分交差判定**：2つの線分が交差するか、端点で接触するかを判定したい場合に適しています。

## 考え方と使い方

端点の向きと線分上の位置関係を調べることで判定できます。 `segments_intersect(a, b, c, d)` を呼びます。端点での接触や一直線上の重なりも交差に含みます。

## 注意・計算量

交点の座標や交差の種類は返しません。複数線分の交差を全列挙する高速なアルゴリズムではありません。

**計算量**：2線分ごと O(1)。

**対応API**：[`segments_intersect`](atcoder::geometry::segments_intersect)。
