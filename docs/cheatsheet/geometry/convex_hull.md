# 点集合を全て含む、最も外側の凸多角形を求めたい、凸包（Andrew法）

## こういうときに使う

**凸包（Andrew法）**：点集合を全て含む、最も外側の凸多角形を求めたい場合に適しています。

## 考え方と使い方

点を辞書順に並べ、外積を利用して内側の点を除去しながら境界を作ります。 `convex_hull(&points)` で反時計回りの凸包頂点列を取得します。

## 注意・計算量

辺上の中間点と重複点は除かれます。すべて一直線なら両端だけを返します。

**計算量**：O(N log N)。

**対応API**：[`convex_hull`](atcoder::geometry::convex_hull)。
