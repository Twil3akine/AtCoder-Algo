# 離れた2つの部分文字列が等しいか、何度も比較したいなら、Rolling Hash

## こういうときに使う

離れた2つの部分文字列が等しいか、何度も比較したい場合に、**Rolling Hash** を用います。

## 考え方と使い方

文字列全体のハッシュを前計算すれば、任意区間のハッシュが定数時間で取得できます。 `RollingHash::new(bytes)` を構築し、`get(l, r)` のハッシュ同士を比較します。

## 注意・計算量

ハッシュが一致しても衝突の可能性はゼロではありません。厳密な一致判定が必要なら元の文字列も比較します。

**計算量**：構築 O(N)、各区間ハッシュ取得 O(1)。

**対応API**：[`RollingHash`](atcoder::string::RollingHash)。
