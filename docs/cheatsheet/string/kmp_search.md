# 長い文字列から、指定したパターンの出現位置を全て探したいなら、KMP法

## こういうときに使う

長い文字列から、指定したパターンの出現位置を全て探したい場合に、**KMP法** を用います。

## 考え方と使い方

パターンの接頭辞情報を再利用するため、照合を先頭からやり直さずに済みます。 `kmp_search(text, pattern)` で重なりを含む全出現位置を求められます。

## 注意・計算量

空パターンは全文字境界に一致します。文字列の添字はバイト列か文字列かで異なります。

**計算量**：O(N + M)。

**対応API**：[`kmp_search`](atcoder::string::kmp_search)、[`prefix_function`](atcoder::string::prefix_function)。
