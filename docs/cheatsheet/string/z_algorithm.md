# 各位置から始まる文字列と、先頭からの共通部分の長さが知りたいなら、Z-algorithm

## こういうときに使う

各位置から始まる文字列と、先頭からの共通部分の長さが知りたい場合に、**Z-algorithm** を用います。

## 考え方と使い方

文字列全体の接頭辞と、各接尾辞の一致長を一括計算します。 `z_algorithm(s)` を使います。特定パターンの検索には `pattern + 区切り + text` の形も使えます。

## 注意・計算量

区切り文字には両方の文字列に出現しない値を選びます。

**計算量**：O(N)。

**対応API**：[`z_algorithm`](atcoder::string::z_algorithm)。
