# 解法チートシート — 問題文から逆引き

アルゴリズム名を思い出すためではなく、**問題文に現れた条件から解法の候補を探す**ための資料です。各項目には着眼点・適用条件・計算量・対応するAPIを掲載します。

| 分野 | 探せる内容 |
| --- | --- |
| [木](crate::cheatsheet::tree) | 直径・中心・重心・距離・パス・全方位木DP |
| [グラフ](crate::cheatsheet::graph) | BFS・0-1 BFS・Dijkstra・SCC・橋・最大流・トポロジカルソート |

## Rustdocで検索する

検索欄で **「最遠点」「同じ色」「共通祖先」「パス上の合計」「無料移動」「橋」「相互到達」** などを入力すると、該当する解法パターンのページが候補に現れます。

Rustdocの検索は本文の全文検索ではありません。ここでは各パターンを独立した公開モジュールにし、`#[doc(alias = "...")]` で問題文に出てきそうな表現を検索語として登録しています。

このモジュールはドキュメント専用です（`cfg(doc)`）。通常のライブラリ利用や提出用バンドルには含まれません。
