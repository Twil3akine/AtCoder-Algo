# 解法チートシート — こういうときに何を使う？

問題文の条件から、使うアルゴリズムを逆引きするための独立したRustdocです。**ライブラリのAPI一覧とは別ページ**に分けています。

## 分野から探す

- [木の問題](crate::tree)：直径・中心・重心・LCA・パス・全方位木DP
- [グラフの問題](crate::graph)：BFS・最短路・SCC・橋・最大流・依存関係

## キーワードで検索する

このページの検索欄に「最遠点」「同じ色」「共通祖先」「無料移動」「橋」「最大マッチング」などを入力すると、対応する解法の項目を検索できます。検索は全文検索ではなく、各項目の名前と `doc(alias)` に設定した別名を対象にしています。
