# 解法チートシート — こういうときに何を使う？

問題文の条件から、使うアルゴリズムを逆引きするための独立したRustdocです。**ライブラリのAPI一覧とは別ページ**に分けています。

## 分野から探す

- [木の問題](crate::tree)：直径・中心・重心・LCA・パス・全方位木DP
- [グラフの問題](crate::graph)：BFS・最短路・SCC・橋・最大流・依存関係
- [データ構造・区間クエリ](crate::data_structure)：連結性、区間集約・更新、転倒数、優先度付き処理
- [配列・並べ替え](crate::array)：座標圧縮、連続区間の圧縮、降順ソート
- [文字列](crate::string)：部分文字列検索、回文、ハッシュ、英字変換
- [数学・数え上げ](crate::math)：剰余、組合せ、素数、累乗、床関数、進数変換
- [幾何](crate::geometry)：点の向き、線分交差、凸包、多角形面積、偏角ソート
- [グリッド・乱択](crate::utility)：4・8近傍の移動、乱択やヒューリスティック探索

## キーワードで検索する

このページの検索欄に「最遠点」「同じ色」「共通祖先」「無料移動」「橋」「最大マッチング」「転倒数」「回文」「座標圧縮」「素因数分解」「凸包」「グリッド」などを入力すると、対応する解法の項目を検索できます。検索は全文検索ではなく、各項目の名前と `doc(alias)` に設定した別名を対象にしています。
