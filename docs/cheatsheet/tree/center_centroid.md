# 木の最大距離を抑えるなら中心、均等に分割するなら重心

## こういうときに使う

- どの頂点までの距離もできるだけ短くなる場所を選びたいとき
- 1頂点を取り除いたとき、残る最大連結成分を小さくしたいとき

## 使うアルゴリズム

**前者には木の中心 `centers()`、後者には木の重心 `centroids()`** を用います。

## 解き方

中心は直径パスの中央の1〜2頂点です。重心は、取り除いた後の各連結成分のサイズが `N / 2` 以下になる1〜2頂点です。

## 注意・計算量

中心と重心は一般には一致しません。辺の距離を最適化する問題と頂点数で分割する問題を混同しないでください。 計算量は **O(N)** です。

**対応するAPI**：[`centers()`](atcoder::graph::tree::centers)、[`centroids()`](atcoder::graph::tree::centroids)
