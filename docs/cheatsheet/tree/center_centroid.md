# 木の中心と重心の使い分け

**問題の手掛かり**：
- ある頂点からの**最大距離**をできるだけ小さくする → **中心**。
- ある頂点を削除したときの**最大連結成分サイズ**をできるだけ小さくする → **重心**。

**着眼点**：両者は目的が異なります。中心は直径の中央にあり、重心は部分木のサイズから判定します。

**解法**：中心は直径パスの中央の1～2頂点。重心は親方向に残る頂点数と、各子部分木の頂点数を比較し、それらがすべて`N/2`以下の頂点を選びます。

**適用条件・注意**：頂点数を基準にした重心です。辺の重みや頂点の重さがある場合は条件を調整します。

**計算量**：いずれも O(N)。

**使うAPI**：[`centers()`](crate::graph::tree::centers)、[`centroids()`](crate::graph::tree::centroids)。
