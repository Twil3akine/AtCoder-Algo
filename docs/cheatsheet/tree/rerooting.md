# 全頂点を根にしたDP・距離の総和

**問題の手掛かり**：「各頂点を根とした場合」の値が全頂点について必要。例えば各頂点から他の全頂点までの距離の総和を求める。

**着眼点**：各頂点から探索をやり直すとO(N²)になりがちです。親→子と子→親の寄与を再利用します。

**解法**：一度根を決めて子側の寄与を集約し、もう一度親側からの寄与を渡します。頂点ごとに周囲の寄与を組み合わせます。

**適用条件・注意**：結合演算や辺・頂点での値の変換を問題のDPに合わせて定義します。DPが定数時間で合成できる場合に線形時間となります。

**計算量**：典型的に O(N)。

**使うAPI**：[`rerooting()`](crate::graph::rerooting::rerooting)。

**練習問題**：[AtCoder ABC220 F — Distance Sums 2](https://atcoder.jp/contests/abc220/tasks/abc220_f)。
