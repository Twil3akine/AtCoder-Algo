# 全頂点をそれぞれ根にしたDPの結果が必要なら、全方位木DP

## こういうときに使う

- 各頂点から全頂点までの距離の総和を求めたいとき
- すべての頂点を1回ずつ根にした場合のDP値を求めたいとき

## 使うアルゴリズム

**全方位木DP（Rerooting DP）**を用います。

## 解き方

一度根を決めて子から親への寄与を計算し、逆方向に親から子への寄与を渡します。各根から探索を繰り返さず、寄与を再利用します。

## 注意・計算量

辺をまたぐ際のDP変換と、寄与の集約演算を問題に合わせて定義します。 計算量は **各集約・変換が O(1) なら全体 O(N)** です。

**対応するAPI**：[`rerooting()`](atcoder::graph::rerooting::rerooting)

**練習問題**：[AtCoder ABC220 F — Distance Sums 2](https://atcoder.jp/contests/abc220/tasks/abc220_f)
