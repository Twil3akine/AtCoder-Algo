# 2頂点間の距離・共通祖先・k番目の頂点

**問題の手掛かり**：木の2頂点間の距離を多数回求める／祖先をたどる／`u`から`v`へ`k`辺進んだ頂点を求める。

**着眼点**：根からの深さと最小共通祖先（LCA）が分かれば、距離やパス上の位置を求められます。

**解法**：任意の頂点を根としてダブリングを構築します。距離は`depth[u] + depth[v] - 2 * depth[lca(u, v)]`です。`jump(u, v, k)`で経路上の移動もできます。

**適用条件・注意**：木が固定されている場合に適しています。`k`が距離を超えると`None`になります。

**計算量**：構築 O(N log N)、問い合わせ O(log N)。

**使うAPI**：[`Lca`](crate::graph::lca::Lca)、[`Lca::distance()`](crate::graph::lca::Lca::distance)、[`Lca::jump()`](crate::graph::lca::Lca::jump)。
