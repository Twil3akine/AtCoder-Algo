# 距離が直径に等しい頂点対を数える

**問題の手掛かり**：木の直径と等しい距離の2頂点を数える。さらに「同じ色」などの端点条件がある。

**着眼点**：すべての直径は木の中心を通ります。各頂点から遠い相手を探すのではなく、**中心に対して候補を分類して数えます**。

**解法**：
- 直径が偶数`D = 2r`：中心頂点から距離`r`の頂点を探します。両端は必ず**異なる子部分木**に属します。分岐ごとに色別の個数を集め、異なる分岐間の組を数えます。
- 直径が奇数`D = 2r + 1`：中心の辺を除いて2側に分け、それぞれ中心の端点から距離`r`の頂点を探します。両側の同じ色の個数を掛けて足します。

**適用条件・注意**：同じ分岐内の頂点対を数えないことが重要です。中心と重心は別の概念です。

**計算量**：O(N)。色の集計には配列やハッシュ表を使います。

**使うAPI**：[`diameter()`](crate::graph::tree::diameter)、[`centers()`](crate::graph::tree::centers)。
