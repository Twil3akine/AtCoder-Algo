# 距離が直径に等しい頂点対を数えるなら、木の中心

## こういうときに使う

- 木の直径と同じ距離になる頂点対を数えたいとき
- 頂点対に「同じ色」などの条件があるとき

## 使うアルゴリズム

**木の中心と、中心からの分岐ごとの数え上げ**を用います。

## 解き方

直径が偶数 `D = 2r` なら中心頂点から距離 `r` の頂点を、異なる子部分木どうしで組み合わせます。奇数 `D = 2r + 1` なら中心辺の左右で、それぞれ端点から距離 `r` の頂点を組み合わせます。色の条件は分岐ごとの色別個数で数えます。

## 注意・計算量

中心が同じでも、偶数直径の場合、同じ子部分木内の2頂点は直径の両端になりません。 計算量は **O(N)（色の集計が定数時間でできる場合）** です。

**対応するAPI**：[`centers()`](atcoder::graph::tree::centers)、[`diameter()`](atcoder::graph::tree::diameter)
