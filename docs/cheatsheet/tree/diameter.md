# 木の中で最も遠い2頂点を求めるなら、木の直径

## こういうときに使う

- 木の中で最も離れた2頂点、または最長の単純パスを求めたいとき
- 直径の長さや、直径上の頂点を知りたいとき

## 使うアルゴリズム

**木の直径（BFSを2回）**を用います。

## 解き方

任意の頂点から最遠点 `a` を探し、`a` からの最遠点 `b` を探します。`a` と `b` を結ぶパスが直径の1つです。

## 注意・計算量

2回の最遠点探索が保証されるのは木です。一般のグラフにはそのまま適用できません。 計算量は **O(N)** です。

**対応するAPI**：[`diameter()`](atcoder::graph::tree::diameter)、[`diameter_info()`](atcoder::graph::tree::diameter_info)

**練習問題**：[CSES — Tree Diameter](https://cses.fi/problemset/task/1131)
