# 辺を追加しながら、2頂点がつながっているか判定したいなら、Union-Find

## こういうときに使う

辺を追加しながら、2頂点がつながっているか判定したい場合に、**Union-Find** を用います。

## 考え方と使い方

連結成分を併合し、2要素が同じグループかを高速に調べます。 最初は各頂点を別集合とし、辺 `(u, v)` ごとに `merge(u, v)` を呼びます。問い合わせは `same(u, v)` です。

## 注意・計算量

通常のUnion-Findでは辺の削除を直接扱えません。

**計算量**：構築 O(N)、併合・判定は償却 O(α(N))。

**対応API**：[`UnionFind`](atcoder::data_structure::union_find::UnionFind)。
