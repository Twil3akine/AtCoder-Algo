# 区間に一括操作した後、指定した1点の値だけ知りたいなら、双対セグメント木

## こういうときに使う

区間に一括操作した後、指定した1点の値だけ知りたい場合に、**双対セグメント木** を用います。

## 考え方と使い方

区間への作用だけを蓄積すればよく、区間集約値を保持する必要がありません。 `apply(l, r, action)` で操作を追加し、`get(i)` で点の値を取得します。

## 注意・計算量

区間和や区間最小値まで求める場合は遅延セグメント木を選びます。非可換な操作は合成順序に注意します。

**計算量**：区間更新・1点取得 O(log N)。

**対応API**：[`DualSegmentTree`](atcoder::data_structure::dual_segment_tree::DualSegmentTree)。
