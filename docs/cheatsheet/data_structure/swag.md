# キューの先頭を削除し、末尾へ追加しながら全体を集約したいなら、SWAG

## こういうときに使う

キューの先頭を削除し、末尾へ追加しながら全体を集約したい場合に、**SWAG** を用います。

## 考え方と使い方

左右2つの集約スタックで、順序を維持しつつ区間結果を再利用します。 `push(x)`、`pop()`、`fold()` で末尾追加・先頭削除・全体集約を扱います。

## 注意・計算量

演算は結合則と単位元が必要です。途中の任意位置の更新には向きません。

**計算量**：各操作 償却 O(1)。

**対応API**：[`Swag`](atcoder::data_structure::swag::Swag)。
