# 毎回、現在の候補の中から最小値・最大値を取り出したいなら、優先度付きキュー（Heap）

## こういうときに使う

毎回、現在の候補の中から最小値・最大値を取り出したい場合に、**優先度付きキュー（Heap）** を用います。

## 考え方と使い方

候補を整列し直さずに優先度の最も高い要素を取り出せます。 最小値優先なら `MinHeap`、最大値優先なら `MaxHeap` を使い、`push` と `pop` を繰り返します。

## 注意・計算量

任意の要素の削除やキー変更は専用APIがありません。古い候補を遅延して捨てる方式を検討します。

**計算量**：追加・取り出し O(log N)、先頭参照 O(1)。

**対応API**：[`MinHeap`](atcoder::data_structure::heap::MinHeap)、[`MaxHeap`](atcoder::data_structure::heap::MaxHeap)。
