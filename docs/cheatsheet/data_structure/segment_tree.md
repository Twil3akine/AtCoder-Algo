# 配列の1点を書き換えながら、区間の合計・最小値を求めたいなら、セグメント木

## こういうときに使う

配列の1点を書き換えながら、区間の合計・最小値を求めたい場合に、**セグメント木** を用います。

## 考え方と使い方

値の更新と、任意区間の結合演算の結果を両立できます。 `SegmentTree::from_vec` で構築し、`set(i, x)` または `update(i, f)`、`get(l, r)` を呼びます。

## 注意・計算量

区間をまとめる演算は結合則を満たし、単位元が必要です。区間全体を更新するなら遅延セグメント木が適しています。

**計算量**：構築 O(N)、1点更新・区間取得 O(log N)。

**対応API**：[`SegmentTree`](atcoder::data_structure::segment_tree::SegmentTree)。
