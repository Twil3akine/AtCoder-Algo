# 要素に加算しながら、先頭からの合計や区間和を求めたいなら、Fenwick Tree（BIT）

## こういうときに使う

要素に加算しながら、先頭からの合計や区間和を求めたい場合に、**Fenwick Tree（BIT）** を用います。

## 考え方と使い方

加算と減算ができる集約なら、セグメント木より簡潔に管理できます。 `add(i, x)` で1点加算し、`sum(l, r)` で半開区間の和を取得します。

## 注意・計算量

任意の結合演算への一般化はできません。最小値・最大値が必要ならセグメント木が適しています。

**計算量**：構築 O(N)、加算・取得 O(log N)。

**対応API**：[`FenwickTree`](atcoder::data_structure::fenwick_tree::FenwickTree)。
