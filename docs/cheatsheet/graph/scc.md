# 有向グラフの相互到達・閉路のある部分の圧縮

**問題の手掛かり**：有向辺に従って2頂点が互いに到達できるか／閉路のある部分をまとめてDAGとして扱いたい。

**着眼点**：相互に行き来できる頂点同士を同じ強連結成分（SCC）にまとめると、成分間のグラフはDAGになります。

**解法**：SCC分解で頂点ごとの成分番号を求め、必要に応じて成分間の辺を構築します。

**適用条件・注意**：有向グラフ向けです。無向グラフの連結成分とは区別してください。

**計算量**：O(V + E)。

**使うAPI**：[`scc()`](crate::graph::scc::scc)、[`SccResult`](crate::graph::scc::SccResult)。

**練習問題**：[CSES — Planets and Kingdoms](https://cses.fi/problemset/task/1683)。
