# 無料移動と有料移動・重みが0と1だけの最短路

**問題の手掛かり**：移動のコストが0か1／通常移動は無料で、ワープだけコスト1。

**着眼点**：重み0の移動先をキューの先頭、重み1の移動先を末尾へ入れると、距離の小さい順に探索できます。

**解法**：両端キュー（`VecDeque`）を使って0-1 BFSを実行します。

**適用条件・注意**：すべての辺のコストが厳密に0または1の場合に限定します。重み2以上があるならDijkstraなどを検討してください。

**計算量**：O(V + E)。

**使うAPI**：[`zero_one_bfs()`](crate::graph::zero_one_bfs::zero_one_bfs)。

**練習問題**：[AtCoder ABC176 D — Wizard in Maze](https://atcoder.jp/contests/abc176/tasks/abc176_d)。
