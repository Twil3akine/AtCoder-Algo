# 依存関係・順番を決める・閉路があるか調べる

**問題の手掛かり**：「Aを終えてからBを実施」「前提条件を満たす順序を1つ出せ」のような依存関係を持つ有向グラフ。

**着眼点**：入次数が0の頂点から順に取り除ければ、全頂点を並べた順序が依存関係を満たします。

**解法**：トポロジカルソートを行います。

**適用条件・注意**：閉路がある有向グラフでは、全制約を満たす順序は存在しません。この実装はその場合`None`を返します。

**計算量**：O(V + E)。

**使うAPI**：[`topological_sort()`](crate::graph::topological_sort::topological_sort)。

**練習問題**：[CSES — Course Schedule](https://cses.fi/problemset/task/1679)。
