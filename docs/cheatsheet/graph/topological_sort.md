# 作業の前後関係を満たす順序を求めるなら、トポロジカルソート

## こういうときに使う

- 「Aの後にBを実行」など、前提条件をすべて満たす順序が必要なとき
- 有向グラフに閉路があるか、順番を決められるか調べたいとき

## 使うアルゴリズム

**トポロジカルソート**を用います。

## 解き方

入次数が0の頂点から順に取り出して削除し、すべての頂点を並べられれば順序が完成します。

## 注意・計算量

閉路がある有向グラフでは条件を満たす順序が存在せず、APIは `None` を返します。 計算量は **O(V + E)** です。

**対応するAPI**：[`topological_sort()`](atcoder::graph::topological_sort::topological_sort)
