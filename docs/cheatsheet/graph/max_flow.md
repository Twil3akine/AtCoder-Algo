# 容量制約のある配送・最大割当・最小カット

**問題の手掛かり**：辺ごとの容量制限を守り、始点から終点へ最大でどれだけ流せるか。二部マッチングとして割当を表せる。

**着眼点**：使った辺を戻せる「残余グラフ」を管理し、増加路を繰り返し見つけます。

**解法**：最大流（Dinic法）を構築します。二部マッチングでは、始点→左側→右側→終点に容量1の辺を張ります。

**適用条件・注意**：容量は非負の整数で指定します。最小カットは最大流を流した後の残余グラフから求められます。

**計算量**：一般には O(V² E)。

**使うAPI**：[`Dinic`](crate::graph::max_flow::Dinic)、[`Dinic::max_flow()`](crate::graph::max_flow::Dinic::max_flow)、[`Dinic::min_cut()`](crate::graph::max_flow::Dinic::min_cut)。
