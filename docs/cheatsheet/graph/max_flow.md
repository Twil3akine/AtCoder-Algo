# 辺ごとの容量制約の下で最大量を流すなら、最大流

## こういうときに使う

- 道路・通信路などの容量を守って、最大で何個流せるか求めたいとき
- 二部グラフの割当数を最大化したいとき

## 使うアルゴリズム

**最大流（Dinic法）**を用います。

## 解き方

容量を持つ辺を張り、残余グラフ上の増加路で流量を増やします。二部マッチングでは始点→左側→右側→終点に容量1の辺を作ります。

## 注意・計算量

容量は非負整数です。最大流を求めた後の残余グラフから最小カットも求められます。 計算量は **一般のグラフで O(V² E)** です。
