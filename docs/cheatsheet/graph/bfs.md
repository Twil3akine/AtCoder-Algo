# 辺の本数が距離になるなら、BFS

## こういうときに使う

- すべての辺の移動コストが等しいとき
- 始点から各頂点までの最短移動回数や到達可能性を求めたいとき

## 使うアルゴリズム

**BFS（幅優先探索）**を用います。

## 解き方

始点から近い順にキューで探索し、最初に訪れたときの距離を記録します。距離の前計算を複数クエリに使うこともできます。

## 注意・計算量

重みが異なる場合は0-1 BFSやDijkstraを検討します。所持アイテムなどが影響するなら、探索状態も拡張します。 計算量は **O(V + E)** です。

**対応するAPI**：[`bfs()`](atcoder::graph::traversal::bfs)
