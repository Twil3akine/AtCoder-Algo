# 重みなしグラフの最短距離・到達可能性

**問題の手掛かり**：辺を何本通るかが距離である／1回の移動コストが全て等しい／到達可能か知りたい。

**着眼点**：始点から近い順に頂点を訪問すれば、初めて訪れたときの距離が最短距離になります。

**解法**：キューを用いるBFSで、各頂点への距離を一度ずつ確定します。全頂点までの距離を前計算して後続のクエリに使えます。

**適用条件・注意**：辺の重みが異なる場合は0-1 BFSまたはDijkstraなどを使います。状態が頂点だけで表せない場合は探索状態を追加してください。

**計算量**：O(V + E)。

**使うAPI**：[`bfs()`](crate::graph::traversal::bfs)。

**練習問題**：[AtCoder ABC209 D — Collision](https://atcoder.jp/contests/abc209/tasks/abc209_d)（木の深さの偶奇を利用）。
