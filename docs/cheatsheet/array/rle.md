# 同じ文字・値が連続する区間をまとめて数えたいなら、ランレングス圧縮（RLE）

## こういうときに使う

同じ文字・値が連続する区間をまとめて数えたい場合に、**ランレングス圧縮（RLE）** を用います。

## 考え方と使い方

同じ値が続く区間を `(値, 長さ)` の列に変換できます。 `iterator.rle()` を使用して、各連続区間の値と個数を取得します。

## 注意・計算量

離れた位置にある同じ値は別のグループです。頻度表とは異なります。

**計算量**：O(N)。

**対応API**：[`RleExt`](atcoder::algorithm::rle::RleExt)。
