# 配列・並べ替え — こういうときに何を使う？

問題文の条件から選べる、実装済みライブラリの逆引きです。

| こういうとき | 用いるアルゴリズム |
| --- | --- |
| 値の大小関係を保ったまま、番号を0からの連番にしたい | [座標圧縮](crate::array::compress) |
| 同じ文字・値が連続する区間をまとめて数えたい | [ランレングス圧縮（RLE）](crate::array::rle) |
| 配列を大きい順に並べたい | [降順ソート](crate::array::descending_sort) |
