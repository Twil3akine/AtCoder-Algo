# 配列を大きい順に並べたいなら、降順ソート

## こういうときに使う

配列を大きい順に並べたい場合に、**降順ソート** を用います。

## 考え方と使い方

昇順に並べて反転する代わりに、降順ソートメソッドを使えます。 安定性が必要なら `sort_reverse()`、不要なら `sort_unstable_reverse()` を使います。

## 注意・計算量

同じ値の相対順序を維持する必要があるか確認してください。

**計算量**：O(N log N)。

**対応API**：[`SortReverse`](atcoder::algorithm::sort::SortReverse)。
