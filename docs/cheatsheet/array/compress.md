# 値の大小関係を保ったまま、番号を0からの連番にしたいなら、座標圧縮

## こういうときに使う

値の大小関係を保ったまま、番号を0からの連番にしたい場合に、**座標圧縮** を用います。

## 考え方と使い方

値の集合が大きくても、実際に登場する値だけに連番を割り振れます。 `Compress::compressed()` で元の列の順位配列と、復元用のソート済み値列を取得します。

## 注意・計算量

元の値との差や距離は圧縮後には保存されません。保存されるのは大小関係と等値関係です。

**計算量**：O(N log N)。

**対応API**：[`Compress`](atcoder::algorithm::compress::Compress)。
