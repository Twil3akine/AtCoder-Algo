# 整数の約数・倍数の条件や周期の一致を扱いたい、最大公約数・最小公倍数

## こういうときに使う

**最大公約数・最小公倍数**：整数の約数・倍数の条件や周期の一致を扱いたい場合に適しています。

## 考え方と使い方

分割可能性や周期の一致を、最大公約数・最小公倍数で表せます。 整数型の `FastMath::gcd` と `lcm` を使います。

## 注意・計算量

最小公倍数は値が大きくなりやすいため、乗算時のオーバーフローに注意します。

**計算量**：最大公約数 O(log max(a,b)) 程度。

**対応API**：[`FastMath`](atcoder::math::fast_math::FastMath)。
