# 数学・数え上げ — こういうときに何を使う？

問題文の特徴をもとに、既存ライブラリの使いどころを探します。

| こういうとき | 用いるアルゴリズム |
| --- | --- |
| 答えを大きな素数で割った余りとして計算したい | [ModInt（剰余整数）](crate::math::mod_int) |
| n個からr個を選ぶ方法や並べる方法を何度も数えたい | [組合せ・順列の階乗前計算](crate::math::combinatorics) |
| 多くの整数について素数判定や素因数分解を繰り返したい | [エラトステネスの篩・最小素因数](crate::math::sieve) |
| 非常に大きな指数の累乗を高速に計算したい | [二分累乗法](crate::math::fast_pow) |
| 整数の約数・倍数の条件や周期の一致を扱いたい | [最大公約数・最小公倍数](crate::math::gcd_lcm) |
| 等差的に増える値を整数除算した商の総和を求めたい | [床関数の和（floor_sum）](crate::math::floor_sum) |
| 整数を2進数・16進数などの各桁へ分解したい | [基数変換・桁列への変換](crate::math::radix) |
| ある上限を超えた値は全部同じ値として扱いたい | [上限付き飽和整数](crate::math::saturating) |
