# 多くの整数について素数判定や素因数分解を繰り返したい、エラトステネスの篩・最小素因数

## こういうときに使う

**エラトステネスの篩・最小素因数**：多くの整数について素数判定や素因数分解を繰り返したい場合に適しています。

## 考え方と使い方

各整数の最小素因数をまとめて前計算すると、繰り返しの問い合わせを高速化できます。 `Sieve::new(limit)` で構築し、`is_prime(n)`、`prime_factorize(n)`、`primes()` を使用します。

## 注意・計算量

判定・分解する数は前計算上限以下にしてください。極端に大きい数1個だけの判定には前計算が不利な場合があります。

**計算量**：構築 O(limit log log limit)、素数判定 O(1)、素因数分解 O(log n)。

**対応API**：[`Sieve`](atcoder::math::sieve::Sieve)。
