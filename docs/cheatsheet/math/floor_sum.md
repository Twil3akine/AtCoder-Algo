# 等差的に増える値を整数除算した商の総和を求めたい、床関数の和（floor_sum）

## こういうときに使う

**床関数の和（floor_sum）**：等差的に増える値を整数除算した商の総和を求めたい場合に適しています。

## 考え方と使い方

`floor((a * i + b) / m)` の和を、商と余りの関係で変形しながら高速に求めます。 `floor_sum(n, m, a, b)` で `i = 0..n` の半開区間の和を計算します。

## 注意・計算量

引数は非負整数で `m > 0` です。答えと中間演算が `u128` に収まる必要があります。

**計算量**：O(log m)。

**対応API**：[`floor_sum`](atcoder::floor_sum::floor_sum)。
