# 答えを大きな素数で割った余りとして計算したい、ModInt（剰余整数）

## こういうときに使う

**ModInt（剰余整数）**：答えを大きな素数で割った余りとして計算したい場合に適しています。

## 考え方と使い方

加減乗除や累乗を、法による剰余を保って計算できます。 `Mod998` や `Mod107` を使い、`ModInt::new(value)` で値を作り、通常の演算子で計算します。

## 注意・計算量

割り算（逆元）は法が素数で、分母が法の倍数でない場合に限ります。乗算の中間値が `i64` に収まる法を選んでください。

**計算量**：加減乗除のうち加減乗算は O(1)、逆元・累乗は O(log MOD) など。

**対応API**：[`ModInt`](atcoder::math::mod_int::ModInt)、[`Mod998`](atcoder::math::mod_int::Mod998)。
