# 非常に大きな指数の累乗を高速に計算したい、二分累乗法

## こういうときに使う

**二分累乗法**：非常に大きな指数の累乗を高速に計算したい場合に適しています。

## 考え方と使い方

指数を2進数で扱い、必要な累乗だけを掛け合わせます。 通常の累乗は `FastMath::fast_pow`、剰余が必要なら `mod_pow(exponent, modulus)` を使用します。

## 注意・計算量

中間積は整数型の範囲を超える可能性があります。`mod_pow` は非負の指数・正の法で使用します。

**計算量**：O(log 指数)。

**対応API**：[`FastMath`](atcoder::math::fast_math::FastMath)。
