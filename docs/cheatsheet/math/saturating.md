# ある上限を超えた値は全部同じ値として扱いたい、上限付き飽和整数

## こういうときに使う

**上限付き飽和整数**：ある上限を超えた値は全部同じ値として扱いたい場合に適しています。

## 考え方と使い方

値が一定以上かだけ分かれば十分な数え上げで、大きな数をその上限に丸められます。 `SaturatingUsize<MAX>::new(value)` を使います。加算・乗算は `MAX`、減算は0で飽和します。

## 注意・計算量

除算・剰余は通常の `usize` 演算です。正確な巨大整数が必要な問題には使えません。

**計算量**：基本の四則演算 O(1)。

**対応API**：[`SaturatingUsize`](atcoder::math::saturating_usize::SaturatingUsize)。
