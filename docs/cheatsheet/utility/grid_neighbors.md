# 二次元盤面で上下左右・斜めのマスを列挙したい、グリッドの4近傍・8近傍

## こういうときに使う

**グリッドの4近傍・8近傍**：二次元盤面で上下左右・斜めのマスを列挙したい場合に適しています。

## 考え方と使い方

方向ベクトルを共通の定数として用いると、探索での方向列挙が簡単になります。 `DIRECTIONS_4` は上下左右、`DIRECTIONS_8` は斜めを含みます。移動先が盤面内か確認してから利用します。

## 注意・計算量

盤面外への移動は自動で除外されません。座標は行・列順のオフセットです。

**計算量**：1マスあたり定数個の候補。

**対応API**：[`DIRECTIONS_4`](atcoder::grid::DIRECTIONS_4)、[`DIRECTIONS_8`](atcoder::grid::DIRECTIONS_8)。
