# 局所探索やランダムテストで再現可能な疑似乱数が必要なら、Xorshift疑似乱数

## こういうときに使う

**Xorshift疑似乱数**：局所探索やランダムテストで再現可能な疑似乱数が必要なら場合に適しています。

## 考え方と使い方

同じseedを渡すと同じ乱数列を生成でき、実験の再現性を保てます。 `Xorshift::new(seed)` で初期化し、`next_u64()` や `range_inclusive(min, max)` を使います。

## 注意・計算量

暗号用途には使えません。範囲生成が暗号学的に一様な乱数である保証もありません。

**計算量**：乱数生成1回 O(1)。

**対応API**：[`Xorshift`](atcoder::random::Xorshift)。
